## Title (max 255)

MamaGate: from danger sign to confirmed arrival, a maternal referral agent for Nigerian health workers on Amazon Bedrock AgentCore

## Description (max 512)

A rules gate in plain code decides in a millisecond whether a pregnant woman must go to hospital now. A Strands agent on Amazon Bedrock AgentCore then completes the referral: hospital and road time from Amazon Location Service, a code-checked referral note, an Amazon SNS pre-alert, and an EventBridge arrival check the hospital closes when she arrives. Family card in English, Pidgin, Hausa, Yoruba and Igbo. Doses are never given.
