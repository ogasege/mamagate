    How MamaGate works
    
      
    
        
    Worker enters findings
    →

    Hospital confirms arrival
    
      
    
      
    
        
    Rules decide urgency
    35 danger-sign rules transcribed from the Nigerian Standing Orders and WHO charts run before any AI. Missing vitals are reported, never read as normal. Urgency can be raised, never lowered.
    
        
    The AI completes the handoff
    A Strands agent follows a referral skill: hospital, note, code check, pre-alert, arrival check. A steering handler enforces the order; hooks lock out anything unsafe.
    
        
    Doses are never given
    Dose questions are refused in code before any model is called, and any dose in model text is removed. The worker is pointed to the right Standing Orders page.

    What this demo does not show
    
      
      
        
    • The rules were transcribed by a software engineer and have not been reviewed by a clinician.
      • 
        
    • Evaluation cases are synthetic and derived from the same guidelines, so they measure fidelity to the rules, not clinical accuracy.
      • 
        
    • Receiving hospitals are synthetic. Real emergency obstetric capability must come from a verified registry; unknown is shown as unknown.
      • 
        
    • No health worker or patient has used MamaGate. Its effect on referral completion is unknown until a pilot measures it.
      • 
        
    • Clinical output is English only. Hausa text would need a native clinical reviewer before use.
